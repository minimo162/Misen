# Finance report workspace rules

- Treat every workbook outside `output/` as a read-only input. Never modify,
  rename, move, or delete an original workbook.
- Create deliverables only under `output/`. Never overwrite an existing file.
- Keep the work limited to the requested reporting month and do not invent
  companies, values, policies, or additional deliverables.
- Use the supplied template as the basis of the report and preserve its
  existing structure, footer, styles, row heights, and column widths.
- Before reporting completion, confirm that the output exists and can be read
  as an XLSX workbook. Report failures and unresolved checks honestly.
- Do not print, copy, or save secrets. Do not add credentials to files,
  commands, logs, or output workbooks.
- Terminal access is a functional capability in this home-PC spike, not proof
  of enterprise containment. Use only commands needed for this workspace.
