# Bullet Hell UX

弾幕シューティングゲーム試作です。

## 操作方法

- WASD / 矢印キー: 移動
- Shift: 低速移動
- Space: 開始（開始後はショット）
- Enter: 開始（開始待ち）
- 開始待ち: ゲーム画面をクリックしてフォーカスし、Space または Enter で開始
- P: ポーズ
- R: リスタート（ゲームオーバー後）

## UX改善内容

- 狭い画面幅でも横スクロールが発生しないレスポンシブレイアウトに調整
- `box-sizing: border-box` 前提のレイアウトへ変更
- ゲーム外に状態表示（スコア、残機、ポーズ、ゲームオーバー）を追加
- `aria-live` による状態変化の読み上げ対応
- プレイヤーが画面外へ移動できない境界制御を追加
- 操作説明と再開方法を常時表示

利用者UXと生成ツール実行ループの検証を目的としたサンプルです。
